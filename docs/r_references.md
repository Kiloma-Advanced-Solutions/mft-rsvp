- **Source:** `AGENTS.md` (repo root) — auto-generated by `next dev`

## Bugs and their fixes

Nothing recorded yet. When a bug takes more than a few minutes, add it here:
the symptom, the cause, the fix, and what would have made it obvious sooner.

The two the codebase already warns about, so nobody has to rediscover them:

- **Hydration mismatch from dates.** Formatting with the ambient locale, or
  reading the clock during a client render, makes the server and the browser
  disagree. `lib/date.ts` pins `en-GB`; `isPast` and the `relative*` helpers
  belong in Server Components or in an effect.
- **A day-key off by one.** `toISOString()` shifts into UTC and can move an
  evening event to the next day. `toDayKey()` uses local getters instead.
