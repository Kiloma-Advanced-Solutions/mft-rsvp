# archive/

Retired and session-specific documents. **Preserved for history, never loaded by
default** — nothing in the reading order points here, and no active document
should link into it except to say "superseded".

Move a document here when it stops being true but is worth remembering: a
convention the team dropped, a decision that was reversed, notes from a session
that has ended. Add one line at the top of the file saying **when** it was
retired and **what replaced it**.

Archive; do not delete. History is cheap. Re-deriving a decision is not.

The active set stays lean enough to read in a minute — that is what this
directory is protecting.
